# AGENTS.md

Coding agents follow the same rules as human contributors: read and follow [CONTRIBUTING.md](./CONTRIBUTING.md) (workflow, quality gate, pre-review checks, code conventions, security).

Two points matter most for agents:

- **Use library controls** (CONTRIBUTING, _Code conventions_): build UI from `src/components/ui` unless there is a compelling reason, stated in a comment.
- **Only the maintainer merges, deploys and releases.** Check the branch's PR state before every push.
